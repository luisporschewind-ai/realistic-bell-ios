# Realistic Bell iOS

一个原生 SwiftUI / SceneKit 铜制手铃仿真：iPhone 锁定竖屏后，利用三轴重力、线性加速度和旋转速度驱动三维铃舌，使正置、倾斜、转圈和上下倒置摇铃都遵循同一套物理状态。

## 当前里程碑

- 参考轻巧小铜铃的空心铃身、木柄、金属连接环和可见铃舌
- 铃舌可在三维锥形边界内全向摆动，包含重力垂落、惯性滞后、碰撞、回弹和边界约束
- 只有真实的铃舌撞壁事件才增加碰撞计数并触发触觉反馈
- 撞击声通过 12 组非谐波铜铃模态合成，允许余音自然叠加
- 持续接触声由铃舌的法向载荷和切向速度驱动：慢速转圈较稀疏、较暗，快速转圈更密、更亮
- 接触层使用固定的多尺度表面粗糙度轨迹激发铜铃高阶模态，不把白噪声或粉红噪声直接混入输出
- 接触更新中断超过 `80 ms` 后自动释放，避免失联状态持续发声
- 声音开关默认关闭；关闭声音会停止音频引擎，不应打断系统音乐
- WAV 采样仅作为模态引擎不可用时的撞击回退，不模拟持续刮擦

## 真机运行

1. 使用 Xcode 打开 `RealisticBell.xcodeproj`。
2. 在 Signing & Capabilities 中选择自己的 Development Team。
3. 连接 iPhone，保持竖屏锁定并运行。
4. 打开“声音”开关后测试；长按铃铛可显示调试参数。

CoreMotion、三维惯性、触觉和最终声音都以真机为验收标准，模拟器不用于最终判断。

## 持续接触声验收矩阵

1. 静止或只把铃舌压在铃壁上：不应出现持续刮擦声。
2. 缓慢转圈：应出现稀疏、安静、偏暗的铜质细颗粒声。
3. 中速转圈：颗粒更密，但仍保留不规则的真实表面感。
4. 快速转圈：声音更亮、更密，不应变成连续白噪声或突兀的“擦擦”声。
5. 慢 → 快 → 慢：音色和密度应连续变化，不应在传感器数据包边界产生点击声。
6. 铃舌脱离后反向撞击：接触层应先释放，随后保留清晰的真实撞击声和余音。
7. 正置与上下倒置摇铃：画面、撞击、接触声、计数和触觉应保持物理一致。
8. 关闭声音并播放系统音乐：本应用不应抢占或中断音乐。

若真机听感需要调整，只修改 `BellContactSoundProfile.smallBrassHandbell` 的声学参数，不用改变已验收的铃铛几何与碰撞物理来迁就声音。
