# Three-Axis Clapper and Modal Bell Audio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a portrait-locked iPhone handbell whose clapper follows three-axis gravity and real inertial motion in every device orientation, then drive a stable real-time modal metal sound engine from the simulator's actual wall impacts.

**Architecture:** `MotionService` remains the 100Hz sensor source. `BellViewModel` owns a pure Swift `BellClapperSimulator`, publishes its three-dimensional state to SceneKit, and routes its `BellImpactEvent` to counting, haptics, and audio. Phase 2 adds a lock-free C modal DSP core behind `AVAudioSourceNode`; the current sample player remains an automatic fallback, and both engines consume the same impact event.

**Tech Stack:** Swift 5, SwiftUI, SceneKit, CoreMotion, AVFoundation, C11 atomics, iOS 17+, Xcode; no third-party runtime dependency.

**Spec:** `docs/superpowers/specs/2026-08-21-3d-bell-design.md`

## Global Constraints

- Lock the application to portrait; the phone itself defines the physical orientation of the bell.
- Use all three gravity, user-acceleration, and rotation-rate axes. Do not reduce motion to `accelerationX` and `rotationZ`.
- Keep physics in bell-local coordinates. The fixed 15.5° presentation tilt is rendering-only.
- Keep `0.36` radians (about `20.6°`) as the hard swing limit, then reduce the active contact angle by azimuth when required by the real inner profile, clapper-ball radius, forward pivot offset, and an `0.008` visual clearance. Initial restitution remains `0.24`.
- Static wall pressure must not repeat collisions; a new dynamic normal impulse may ring while the phone is inverted.
- Only `BellImpactEvent` may increment the counter or trigger haptics/audio. Sensor thresholds must not independently guess collisions.
- CoreMotion target rate is 100Hz; SceneKit target rate is 60Hz.
- Sound remains off by default. Physics, visual motion, counting, and haptics continue while sound is off.
- Audio must mix with other apps and release its session when disabled or stopped.
- Preserve the approved bell geometry, scale, materials, lighting, camera, layout, and bounded manual pan.
- The app targets iOS 17+ and adds no third-party model, sound, or runtime package.
- This directory is not a Git repository. Each task ends with a verification checkpoint instead of a commit; do not initialize Git without separate authorization.

struct BellMotionInput: Equatable {
    let gravity: SIMD3<Double>
    let userAcceleration: SIMD3<Double>
    let rotationRate: SIMD3<Double>
    let timestamp: TimeInterval

    static let zero = BellMotionInput(
        gravity: SIMD3(0, -1, 0),
        userAcceleration: .zero,
        rotationRate: .zero,
        timestamp: 0
    )

    init(sample: MotionSample) {
        gravity = SIMD3(sample.gravityX, sample.gravityY, sample.gravityZ)
        userAcceleration = SIMD3(
            sample.accelerationX,
            sample.accelerationY,
            sample.accelerationZ
        )
        rotationRate = SIMD3(sample.rotationX, sample.rotationY, sample.rotationZ)
        timestamp = sample.timestamp
    }

    var isFinite: Bool {
        gravity.x.isFinite && gravity.y.isFinite && gravity.z.isFinite &&
        userAcceleration.x.isFinite && userAcceleration.y.isFinite && userAcceleration.z.isFinite &&
        rotationRate.x.isFinite && rotationRate.y.isFinite && rotationRate.z.isFinite &&
        timestamp.isFinite

}

- [ ] **Step 5: Implement vector helpers and input sanitization.**

  Keep helpers private and deterministic:

  ```swift
  private func dot(_ a: SIMD3<Double>, _ b: SIMD3<Double>) -> Double {
      a.x * b.x + a.y * b.y + a.z * b.z
  }

  private func cross(_ a: SIMD3<Double>, _ b: SIMD3<Double>) -> SIMD3<Double> {
      SIMD3(
          a.y * b.z - a.z * b.y,
          a.z * b.x - a.x * b.z,
          a.x * b.y - a.y * b.x
      )
  }

  private func normalized(_ value: SIMD3<Double>, fallback: SIMD3<Double>) -> SIMD3<Double> {
      let length = sqrt(dot(value, value))
      return length.isFinite && length > 1e-9 ? value / length : fallback
  }
  ```

If elapsed time exceeds `maximumAccumulatedTime`, reset the timestamp and rotation baselines without integrating the stale interval or emitting an impact. For valid elapsed time, accumulate it and run zero or more exact `fixedTimeStep` substeps; retain the fractional remainder for the next sample. On invalid input, retain the last stable direction, damp velocity, and emit no impact.

- [ ] **Step 6: Implement each fixed rotating-frame pendulum substep.**

  Use the bell mouth axis `(0,-1,0)`, `dt = parameters.fixedTimeStep`, gravity in units of `9.80665 m/s²`, and the following state update for each accumulated substep:

  ```swift
  let pivotAcceleration = input.userAcceleration * (9.80665 * parameters.translationGain)
  let angularAcceleration = clampMagnitude(
      (input.rotationRate - previousRotationRate) / dt,
      maximum: 40
  )
  let radius = state.direction * parameters.length
  let tangentLinearVelocity = state.tangentVelocity * parameters.length
  let rotatingFrameAcceleration =
      -cross(angularAcceleration, radius) -
      cross(input.rotationRate, cross(input.rotationRate, radius)) -
      2 * cross(input.rotationRate, tangentLinearVelocity)
  let effectiveAcceleration =
      normalized(input.gravity, fallback: lastStableGravity) * 9.80665 -
      pivotAcceleration +
      rotatingFrameAcceleration * parameters.rotationGain
  let tangentAcceleration = effectiveAcceleration -
      state.direction * dot(effectiveAcceleration, state.direction)
  var velocity = state.tangentVelocity + tangentAcceleration / parameters.length * dt
  velocity *= exp(-parameters.damping * dt)
  velocity = clampMagnitude(velocity, maximum: parameters.maximumAngularSpeed)
  var direction = normalized(state.direction + velocity * dt, fallback: state.direction)
  velocity -= direction * dot(velocity, direction)
  ```

  Store `previousRotationRate` only after a valid step. The first sample initializes the baseline and returns the current state without an impact.

- [ ] **Step 7: Implement conical projection and collision response.**

  For `axis = (0,-1,0)`, split direction into axial and radial components. At the boundary use:

  ```swift
  let radialDirection = normalized(direction - axis * dot(direction, axis), fallback: lastSide)
  direction = axis * cos(parameters.maximumAngle) +
      radialDirection * sin(parameters.maximumAngle)
  let outwardNormal = normalized(
      -axis * sin(parameters.maximumAngle) +
      radialDirection * cos(parameters.maximumAngle),
      fallback: radialDirection
  )
  let outwardAngularSpeed = max(0, dot(velocity, outwardNormal))
  velocity -= outwardNormal * outwardAngularSpeed * (1 + parameters.restitution)
  velocity -= direction * dot(velocity, direction)
  ```

  Preserve the velocity component tangent to the cone. Persist `lastSide` whenever radial magnitude is reliable so exact inversion cannot randomly choose another side.

- [ ] **Step 8: Emit crossing and continuous-contact impacts without repeats.**

  Convert outward angular speed to `normalSpeed = outwardAngularSpeed * parameters.length`. Also maintain an exponential baseline of outward contact drive. A collision candidate exists when either a new boundary crossing exceeds `minimumImpactSpeed`, or a new high-pass contact impulse exceeds `contactImpulseThreshold`. Normalize strength with:

  ```swift
  let strength = clamp(
      (normalSpeed - parameters.minimumImpactSpeed) /
      (parameters.fullStrengthImpactSpeed - parameters.minimumImpactSpeed),
      0,
      1
  )
  ```

  Require `timestamp - lastImpactTime >= collisionCooldown`. Construct `contactPoint` as `direction * parameters.length` and `tangentialSpeed` as the magnitude of the cone-tangent velocity times the clapper length.

#define BELL_MODAL_MAX_MODES 30
#define BELL_MODAL_EVENT_CAPACITY 32

typedef struct {
    float frequency_hz;
    float decay_seconds;
    float gain;
} BellModalMode;

typedef struct {
    double timestamp;
    float strength;
    float normal_speed;
    float contact_x;
    float contact_y;
    float contact_z;
    float tangential_speed;
} BellDSPImpact;

BellModalDSP *BellModalDSPCreate(

    const BellModalMode *modes,

void BellModalDSPDestroy(BellModalDSP *dsp);
void BellModalDSPReset(BellModalDSP *dsp);
bool BellModalDSPEnqueueImpact(BellModalDSP *dsp, BellDSPImpact impact);

    float *left,
    float *right,
    unsigned int frame_count

- [ ] **Step 4: Implement fixed-size allocation and the C11 SPSC queue.**

  Allocate all mode/channel state in `BellModalDSPCreate`. Use `_Atomic unsigned int` read/write indices with release/acquire ordering. The producer writes the event payload before publishing the write index; the render consumer reads the payload only after acquiring that index. `BellModalDSPRender` must contain no `malloc`, `free`, mutex, file I/O, logging, or callback into Swift.

- [ ] **Step 5: Implement damped non-harmonic resonators.**

  Precompute each mode's recurrence coefficients during creation. `decay_seconds` uses T60 semantics: it is the time for modal amplitude to reach approximately `0.001` (−60 dB), matching the acoustic-output decay test:

  ```c
  radius = expf(logf(0.001f) / (decay_seconds * sample_rate));
  coefficient = 2.0f * radius * cosf(2.0f * M_PI * frequency_hz / sample_rate);
  radius_squared = radius * radius;
  y = coefficient * y1 - radius_squared * y2;
  ```

  Maintain separate left/right `y1` and `y2` values. On impact, add excitation to existing state instead of resetting it so the linear modes naturally overlap.

- [ ] **Step 6: Map physical impact fields into sound variation.**

  Use equal-power left/right gains from clamped `contact_x`. Modulate each mode by its index phase and `contact_z`; scale high-frequency modes more strongly with `strength`. Add a deterministic xorshift-noise transient whose initial envelope is proportional to `tangential_speed` and decays below audibility within 50ms. Apply a soft limiter `x / (1 + fabsf(x))` to the final output.

```swift
protocol BellAudioPlaying: AnyObject {
    @discardableResult func prepare() -> Bool
    @discardableResult func play(impact: BellImpactEvent, config: BellConfig) -> Bool
    func stop()
}

enum BellAudioBackend: Equatable {
    case stopped
    case modal
    case sampleFallback
}

enum BellAudioRoutingPolicy {
    static func preparedBackend(modalReady: Bool, sampleReady: Bool) -> BellAudioBackend {
        if modalReady { return .modal }
        if sampleReady { return .sampleFallback }
        return .stopped
    }

    static func eventBackend(
        active: BellAudioBackend,
        modalAccepted: Bool,
        sampleReady: Bool
    ) -> BellAudioBackend {
        if active == .modal && modalAccepted { return .modal }
        return sampleReady ? .sampleFallback : .stopped
    }
}

final class BellAudioEngine: BellAudioPlaying {
    private(set) var activeEngine: BellAudioBackend = .stopped
}
```
